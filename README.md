## 🌟 Highlights & Features

- ⚡ **Live Headlines Feed:** Fetches up-to-the-minute global and local news via RESTful endpoints.
- 🗂️ **Category Explorer:** Filter by Business, Technology, Entertainment, Sports, Science, and Health.
- 🔍 **Interactive Article View:** In-app detailed article reader with external browser link support.
- 🎨 **Adaptive Color System:** Clean visual hierarchy with high-contrast readable typography.
- 📱 **Cross-Platform:** Runs seamlessly on Android, iOS, Web, and Desktop.

## 🚀 Quick Start

### 1. Prerequisites
- [Flutter SDK](https://docs.flutter.dev/get-started/install) (3.0+)
- Dart 3.0+

### 2. Setup & Execution
```bash
# Clone the repository
git clone https://github.com/bibasshrestha980-npl/news_app.git

# Enter project directory
cd news_app

# Install dependencies
flutter pub get

# Launch the app
flutter run
```

---

## 🏛️ Project Architecture

```
lib/
├── common/         # App theme, typography, and color palettes
├── data/           # Category constants and static mappings
├── models/         # News article and source data models
├── providers/      # NewsProvider managing async API state
└── screens/        # Home, Onboarding, and Category views
```
